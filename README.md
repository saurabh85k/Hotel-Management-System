# 🏨 Hotel Management System (Salesforce Capstone Project)

A comprehensive Salesforce application built to automate hotel operations, manage room bookings, and prevent double-booking. This project combines **Salesforce Admin** and **Developer** skills to create a seamless end-to-end system.

## 🚀 Features

*   **Custom Objects:** Room, Guest, Reservation, Hotel Staff.
*   **Admin Configuration:** Validation Rules, Formula Fields, and Default Values.
*   **Automation (Flows):** 4 Record-Triggered Flows to handle Email Notifications, Room Status Updates (Occupied/Cleaning), and Cancellation Alerts.
*   **Development (Apex & SOQL):** Custom Apex Trigger (`ReservationTrigger`) and Handler class to prevent overlapping room bookings. SOQL queries for data retrieval.
*   **Security:** Role Hierarchy, Organization-Wide Defaults (Private), and Permission Sets for least-privilege access.
*   **Reports & Dashboards:** Real-time visual tracking of Room Occupancy and Reservation Revenue.

## 🛠️ Tech Stack
*   Salesforce Admin (Lightning Experience)
*   Apex (Triggers, Classes)
*   SOQL (Salesforce Object Query Language)
*   Flows (Record-Triggered Automation)
*   Git & GitHub (Version Control)
